# benkesmith-speech-recorder

[![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

A Cordova plugin for **recording WAV audio** to be used for speech recognition. Works on both **Android** and **iOS**.

## Installation

```bash

```
